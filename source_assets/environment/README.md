# Environment authoring sources

These are editable Blender 4.5.14 LTS sources, generated by
`tools/build_environment_assets.py`. The source collection preserves a fused,
high-density root/trunk/fork surface and full shaped leaf laminae. Each tree's
full-density mother is in `tree_name.blend`; its editable near/middle/far game
representations are in `tree_name_runtime_lods.blend`. Both preserve the complete
geometry, while the largest native file stays below 68 MiB. In the understory file the editable specimens are laid out on a grid;
the exported specimens are all restored to their local origins.

Six broadleaf mother trees contain approximately 2.556m–2.564m triangles each.
Three dead-tree mothers contain approximately 303k–325k triangles each. These
numbers describe the mesh topology and do not establish a commercial-quality
visual acceptance result. Review the actual Godot material, near silhouette,
leaf attachment, scene lighting and runtime camera before acceptance.

The botanical geometry, curved grass, rachis-supported fern pinnae, branch-
supported shrubs, rolled leaf litter and weathered stone forms are original
procedural authoring for this project. They are not downloaded 3D meshes.
The leaf venation color/normal images are authored from the explicit venation
construction in the generator and are not photographed plant textures.

Scanned stone color, roughness and lossless OpenGL normal textures come from
[Poly Haven Rock 3, by Rob Tuytel](https://polyhaven.com/a/rock_3) under CC0. Exact downloaded
URLs, lengths, provider MD5 checks and independently calculated SHA-256 hashes
are recorded in `assets/refined/environment/textures/STONE_PBR_SOURCE.json`.
The bark and forest-floor scans supplied by the project integration pipeline
have their own source records and explicit runtime binding manifest. External
scanned images are not claimed as original artwork.

Generation:

```sh
Blender --background --threads 4 --python tools/build_environment_assets.py
```

`-- --sample` creates a representative live tree, dead tree and understory kit.
`-- --resume` retains completed high-density sources, validates and exports
their runtime meshes, and generates missing variants. `-- --terrain-only`
updates the understory kit while retaining the tree manifest. `-- --repair-exports`
validates and re-exports the current runtime meshes from the retained sources.
`-- --resume --crown-rebuild` regenerates the six live branching crown structures
while retaining the three already authored dead-tree mothers.
`-- --split-sources` separates an existing combined mother/game source without
reducing geometry. `-- --far-core-only` derives the far structural silhouette
from the largest fused root/trunk/scaffold component while preserving the
near/middle meshes and leaf population.

Each live tree has 10,080 leaves supported by 1,260 terminal twig sites. Near
retains every leaf with visible petiole, curved lamina, rolled margin and rib
geometry; middle retains 5,040 distributed leaves; far retains 1,680. Their
projected size grows moderately at distance to preserve crown mass rather than
leaving an empty shell. Leaf color/normal venation images are authored at 4K.
The top/underside material response differs. Highest-detail leaves and their
shadow cost are confined to nine metres; middle/far preserve full crown cover.
`PHYSICS_ENVELOPE.json` retains the exact collision radius/height from the
previous accepted tree resources, so denser branch/leaf geometry does not alter
route collision. The original continuous-frame and 180-section regression is
retained.

The `.gdignore` file keeps these authoring sources out of Godot's live imports.
The game directly consumes `assets/refined/environment/*.glb` and the scanned
material bindings, with shared immutable mesh/material resources and separate
scene nodes/colliders. Cosmetic understory contains no collision objects.

The generation manifest is `assets/refined/environment/ENVIRONMENT_MANIFEST.json`.
The isolated Godot review scene is `scenes/environment_quality_preview.tscn`.
The geometry, PBR dimensions, paused wind and local batch bounds contract is
`tests/environment_quality_contract.tscn`.

The generator transports each tube frame continuously along its centerline.
This prevents a nearly vertical tangent from flipping the ring basis and
producing a circumferential pinch after voxel fusion. The regression contract
checks the actual horizontal contour and minimum radius of 180 trunk sections
across all nine variants' near/middle runtime representations.
