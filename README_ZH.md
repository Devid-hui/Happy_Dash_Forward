# The Midnight Academy — The Rainfield

《午夜学院：雨夜平原》是 Godot 4 第一人称微恐怖逃生原型。你在暴雨、黑暗与闪电之间搜集三份研究记录，利用学科能力避开五只奶龙追猎者，最终抵达学院出口。

## 环境与运行

- 引擎：**Godot 4.7.2 Standard**，GDScript；渲染器：Forward+。macOS 可使用 Universal 引擎运行。
- 本仓库提供源码，**没有随仓库分发可运行的 `.app`**。
- 用 Godot Project Manager 导入本目录的 `project.godot`，按 F5 运行整个项目；终端也可执行 `godot --path .`。
- 设计视口为 640×360，默认窗口为 1280×720，采用整数缩放。黑暗、阴影、体积雾和雨效需要在实际图形窗口中检查。
- 设置提供亮度切换及“减少闪光”。减少闪光会降低闪电亮度、延长间隔；仍保留闪电。

## 操作与本局流程

| 操作 | 按键或行为 |
| --- | --- |
| 移动 / 观察 | WASD / 鼠标 |
| 奔跑 / 交互 | Shift / E |
| 三个技能槽 | 1 / 2 / 3 |
| 研究手册 | Tab；打开后暂停并释放鼠标，关闭后恢复打开前状态 |
| 雨声频段 | F，轮换低频、中频、高频 |
| 暂停 | Esc；手册打开时优先关闭手册，再按 Esc 切换暂停 |
| 切出游戏 | 自动暂停；切回后点击“继续”或按 Esc 才恢复 |

开始时选择 1–3 门学科；未选择时自动装备雷痕、还声和泥浆。三份绿色研究书分别在输电塔、枯树和废车旁的木箱上。HUD 提供最近未收集目标的方向与距离；靠近三米以内按 E 收集。记录依装备顺序轮流把技能设为 Lv.2，重复升级仍停在 Lv.2。收齐三份后到学院出口按 E 逃脱，连续两次被追猎者撞击则失败。

地图地面为 200×200 米，四边设碰撞边界；异常坠落到 `y < -5` 会结束本局。手册、暂停和结局会冻结游戏计时，包括技能冷却和残像。

## 六项学科能力

所有成功施放的技能都有八秒冷却。科学提供设计启发，泥浆规则和盐阵的即时生物效果属于梦境玩法近似，不代表现实实验效果。

| 技能 | 当前实际效果 | 消耗、限制与升级 |
| --- | --- | --- |
| 雷痕 | 闪电后五秒内保存敌人在闪电时的旧屏幕位置；残像不会追踪移动目标 | 消耗 8 点体力；Lv.1 持续 2.5 秒，Lv.2 为 3.5 秒；无近期闪电时施放失败 |
| 还声 | 发出回声环并标亮研究书；追猎者始终追踪玩家 | 无额外资源消耗；专属 Lv.2 效果未完成；不会通过声源诱导追猎者改换目标 |
| 蓝色供词 | 鲁米诺显影尚未被雨冲淡的普通与盐反应痕迹 | 初始三份试剂，每次消耗一份；Lv.2 保留普通痕迹，并强化盐反应痕迹的蓝光 |
| 不许停步之泥 | 在前方铺设泥区；低速通过者更受阻，玩家与追猎者受相同规则影响 | 雨中约 11 秒后消失；半径 Lv.1 为 2.4 米，Lv.2 为 3.1 米 |
| 盐之誓约 | 在脚下放置盐阵，减缓进入其中的追猎者并留下反应痕迹 | Lv.1 消耗 22 点体力、半径 2.4 米；Lv.2 消耗 30 点、半径 3 米；约 36 秒内体力恢复较慢，盐阵约 11 秒后消失 |
| 剥噪 | 十秒内降低雨声音量，并保留 F 所选频段、衰减其余雨声频率 | 不改变敌人、脚步或雷声；专属 Lv.2 效果未完成 |

盐反应痕迹按敌人及当前有效痕迹去重；原痕迹被雨冲淡后，追猎者再次处于盐阵中可以生成新痕迹。鲁米诺只显示仍存在的痕迹，干净地面不会凭空发光。

手册列出四组融合记录：剥噪生效时还声（谱化回声）、雷痕残像期间还声（过去与现在）、布泥后还声（诱导沉陷）、盐阵影响追猎者留下反应痕迹后使用鲁米诺（盐渍证言）。必须同时装备组合中的两项能力并满足实际操作条件。融合写入手册，不产生额外技能；通知只显示短标题，完整条件和说明在手册中查看。

## 当前追猎与雷暴规则

- 保持 **五只**追猎者，初次环绕玩家生成。普通速度 **3.2**，距离八米内进入 **0.8 秒**预警，随后以 **7.8** 冲刺 **2 秒**，再休息 **8 秒**。盐阵、泥区和眩晕会影响开始冲刺的条件。
- 玩家步行 **5.0**、奔跑 **7.5**；后退或斜后退限速 **2.5**，Shift 不会使后退消耗奔跑体力。前行奔跑每秒消耗 25 点体力，正常恢复每秒 17 点，盐阵的脱水状态下恢复每秒 7 点。
- 玩家实际奔跑、后方敌人落后至少 **28 米**且视野中没有敌人时，每批最多三只传送到实际移动方向前方 **16–24 米**，批次间隔八秒。位置检查避开障碍及其他敌人；保留血量并进入休息。视野保护根据真实模型世界包围盒判断，不能把仍进入视锥的模型传走。
- 每只血量默认 100，属性和状态独立；死亡后补位。当前玩家技能没有直接伤害。树林使用近距离射线避障，尚未实现复杂导航网格寻路。
- 闪电在地图 ±85 米内落下，显示分叉光束，由落点上方的单个阴影点光照明；雷声根据距离延迟。正常间隔 **3.2–6.4 秒**，减少闪光为 **4.4–7.6 秒**，另加单次闪电 0.42 秒。
- 近身补光范围 4.5 米，帮助辨认地面和障碍；远处主要由雷光揭示。该补光和单点闪电是实时游戏近似。

## 验证与性能测量

使用 Python 3 和匹配的 Godot 4.7.2 运行统一入口：

```bash
python3 tests/run_tests.py --godot /path/to/godot
```

入口依次检查资源导入、错误判定自测、菜单与本局 smoke、敌人规则和审计回归。非零退出、超时、引擎/脚本错误或缺少成功标记均判失败；自测故意制造“退出码为零且已有 PASS 字样”的断言错误，确保仍被拒绝。GitHub Actions 使用同一入口。不要单独凭 Godot 的退出码判断测试成功。

图形性能测量单独运行，期间保持其他 GPU 工作空闲：

```bash
python3 tests/run_performance.py --godot /path/to/godot --output /path/to/results
```

默认三组，每组预热五秒后采样六十秒，640×360、Forward+，关闭垂直同步和帧率上限。首组额外连续重建世界十次，记录引擎内存、节点数量及进程 RSS；后两组不重复重建压力检查。保存逐帧 CSV、引擎/硬件元数据、日志和汇总 JSON。帧间隔是墙钟观测。Godot 4.7.2 的 `TIME_PROCESS` 每秒更新一次，记录上一窗口处理时间的最大值，因此 CSV 中会重复这个监测值；它的分位数不等于逐帧处理时间分位数，也不能当作独立 GPU 耗时。实现见 [Godot 4.7.2 主循环源码](https://github.com/godotengine/godot/blob/4.7.2-stable/main/main.cpp#L4757)。

性能场景使用固定种子、镜头路线及落雷时序，保留五只追猎者 AI、森林、雨效和音频；只在该测试场景抑制失焦/结局暂停，并通过脚本设置玩家位置。因此它不验证行走碰撞、技能操作、难度或自然逃脱，也不覆盖技能集中施放或奔跑时回收扫描的完整处理成本。命令行回归、性能测量与真实用户输入验收分别记录，不能相互替代。

## 资产与 macOS 导出

森林使用 Kenney Nature Kit CC0 资产，来源见 [assets/forest/ASSET_LICENSE.txt](assets/forest/ASSET_LICENSE.txt)；两条雨声循环来自 OpenGameArt CC0，来源见 [assets/audio/ASSET_LICENSE.txt](assets/audio/ASSET_LICENSE.txt)。雷声、脚步和追猎者声音仍含程序合成占位音效。追猎者由脚本生成低模 3D 模型，网格与材质通过模板缓存共享；节点、碰撞、血量和 AI 状态各自独立。更换模型见 [README_ASSETS.md](README_ASSETS.md)。

原参考图片保留在源码目录，未被游戏加载，导出时排除。仓库没有根源码许可证，部分参考图片的来源和授权仍待明确；森林与音频的 CC0 记录不构成整个项目的许可。

要生成本地 macOS 调试包，先安装 Godot 4.7.2 匹配的 Export Templates，然后执行：

```bash
mkdir -p builds
godot --headless --path . --export-debug macOS builds/TheMidnightAcademy.app
```

导出预设保留运行资源，排除测试、文档、预览脚本/场景和未使用参考图片。当前未配置正式 Developer ID 签名与公证；本地调试构建不等于可公开发行的已公证应用。

## 当前限制与调整入口

工程仍是原型。还声/剥噪的专属 Lv.2 效果、石碑重新配置技能、生命数值 HUD 和复杂避障尚未完成。亮度、雨声层次、飞溅与混音需要实际显示器/耳机验收；自动胜利用例不证明真实用户完成了整局。

玩家速度和体力在 `scripts/player/player.gd`；敌人默认参数在 `resources/enemies/nailong_default.tres`；数量与回收在 `scripts/enemies/hunter_director.gd`；雷暴在 `scripts/world/storm_controller.gd`；环境、雨效、痕迹和技能区域在 `scripts/world/world.gd`。修改参数后运行统一回归，并对受影响的图形和输入行为进行实际窗口测试。
