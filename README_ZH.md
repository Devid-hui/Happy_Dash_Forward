# The Midnight Academy — The Rainfield

《午夜学院：雨夜平原》是一个 Godot 4 第一人称微恐怖逃生原型。你在暴雨、黑暗与闪电之间搜集三份研究记录，利用学科能力避开奶龙追猎者，最终抵达学院出口。

## 环境与运行

- 目标引擎：Godot 4.7.2 Standard（GDScript，macOS Universal，兼容 Apple Silicon）。
- 渲染器采用 Forward+，用极低环境光维持黑暗；玩家近处的阴影光、低密度体积雾、潮湿地面反射与实时闪电共同塑造可读性。
- 地图已加入 Kenney Nature Kit 的低模树群，围成林间空地并保留地标视线；来源和 CC0 许可见 `assets/forest/ASSET_LICENSE.txt`。
- 暴雨包含 GPU 雨线、地面碰撞飞溅、湿地高光，以及两条 OpenGameArt CC0 实录雨声循环；来源见 `assets/audio/ASSET_LICENSE.txt`。
- 在 Godot Project Manager 中导入本目录的 `project.godot`，再按 F6/F5 运行；也可在终端执行 `godot --path .`。
- 初始设计视口为 640×360，窗口为 1280×720。

## 操作

WASD 移动，鼠标观察，Shift 奔跑，E 交互，1/2/3 释放三个技能槽，Tab 查看研究手册，F 切换频段提示，Esc 暂停并释放鼠标。点击继续后重新捕获鼠标。连续两次被奶龙撞击会失败。

## 六项学科能力

| 技能 | 依据与玩法 | 代价/限制 |
| --- | --- | --- |
| 雷痕 | 闪电后的视觉后像，记住旧轮廓 | 需刚发生闪电；会造成视觉重影 |
| 还声 | 声学回声脉冲，短暂标出近处目标 | 追猎者会调查声音位置 |
| 蓝色供词 | 鲁米诺只显影仍存在的反应性痕迹 | 试剂有限，雨水冲淡痕迹，蓝光暴露位置 |
| 不许停步之泥 | 以剪切增稠近似做成区域阻碍 | 玩家和奶龙遵守同一规则；慢行更受阻 |
| 盐之誓约 | 以渗透压为依据的梦境盐阵 | 消耗体力，短时减缓生物；雨水稀释 |
| 剥噪 | 以频率分解为主题的听觉状态与频段选择提示 | 过滤也会损失同频危险信息 |

现实科学只提供原理启发。盐阵对怪物造成的即时脱水等效果属于梦境超自然夸张，不是现实盐圈的能力。

## 升级、融合与流程

三份记录分别位于输电塔、枯树与废车附近。拾取记录会推进剧情并解锁出口，并依次把装备中的技能提升到 Lv.2：雷痕延长残像时间、泥浆扩大作用范围、盐阵扩大范围但消耗更多体力、鲁米诺优先确认盐阵反应痕迹；其它技能的完整升级效果还未完成。

融合组合在手册中列出：还声+剥噪（谱化回声）、雷痕+还声（过去与现在）、还声+泥浆（诱导沉陷）、盐阵+鲁米诺（盐渍证言）。融合记录依据实际先后条件发现：滤波中发声、残像期间发声、布泥后发声、或盐阵影响追猎者留下反应性痕迹后显影。发现记录后可在手册说明中查看；这些机制是轻量玩法近似，不是完整的实验教学系统。

## 调整参数

- 闪电频率、持续时间、减闪模式：`scripts/world/world.gd` 的 `_process`。
- 暗度、雾密度与玩家近距离可见范围：`_build_environment` 与 `scripts/player/player.gd` 的 OmniLight3D 参数。
- 玩家速度、体力：`scripts/player/player.gd` 顶部参数。
- 奶龙速度、侦测距离和攻击距离：`scripts/enemies/hunter.gd`。
- 近地可见度与雨线：`scripts/player/player.gd` 的 OmniLight3D 和 `scripts/world/world.gd` 的地面材质、雨粒/飞溅参数。
- 设置菜单提供“减少闪光”；当前主要通过降低亮度并延长间隔实现。

## 替换奶龙模型

追猎者当前是 `scripts/enemies/hunter.gd` 生成的低模 3D 奶龙，身体接受场景灯光；无闪电时只能看见微弱绿眼与近处的暗部轮廓，闪电时会显出全身。原透明图 `assets/nailong/nailong_pixel.png` 作为美术参考保留。更换完整 `.glb` 模型的方法见 [README_ASSETS.md](README_ASSETS.md)。

## 当前限制

- 当前工程是可玩原型，不是经过完整人工试玩打磨的发行版。
- 森林使用 Kenney CC0 树模型，雨声使用 OpenGameArt CC0 实录循环；闪电雷声、脚步与奶龙呼吸仍为程序合成占位音效。雨声层次、雨滴飞溅和灯光已加入，仍需要在目标显示器/耳机上人工校准亮度和混音。
- Lv.2 实质效果目前覆盖雷痕、泥浆、盐阵和鲁米诺，其它技能的专属升级方向未完成；场景石碑重新配置技能、玩家生命数值 HUD 与 NavigationAgent 复杂避障未完成。
- 画面、输入、视听体验应在实际 Godot 图形窗口中人工验收；命令行解析或启动不能替代完整玩法测试。

## 十只奶龙追逐规则（2026-10-12）

- 玩家前行 5.0、奔跑 7.5；后退与斜后退 2.5，Shift 无效且不消耗奔跑体力。切换后退时立即限制水平速度，不能靠上一帧奔跑惯性逃过限速。
- 全图保持十只奶龙，始终锁定玩家；第三份记录不会再额外生成第十一只。普通速度 3.7，受盐和泥地技能影响时仍可减速。
- 距离 10 米内触发 0.8 秒尖叫预警，然后以 8.2 冲刺 5 秒，再以普通速度休息 8 秒。预警/休息不能重新启动冲刺；眩晕会中断冲刺。预警声音为自制程序合成短尖叫，位置音频让远处敌人声音减弱。
- 超过 65 米时，刷新到实际水平运动方向前方 ±55°、距离 22–34 米的位置。停止移动时沿用上一次运动方向。位置查询避开树干、障碍及其他奶龙；刷新保留血量和状态减益，但重置冲刺为休息。如果扇区内没有合法点，保留当前位置并在后续检查重试。
- 默认每只血量 100，暴露 `take_damage(amount)` 方法和死亡事件；当前玩家技能没有新增直接伤害。死亡会补位以维持十只。

### 解耦与扩展

`resources/enemies/nailong_default.tres` 是属性模板，可在 Godot 中修改。每只敌人进入场景时复制模板，血量、冷却、减速和冲刺状态都是自己的，改变一只不会改变其他九只。

- `hunter.gd`：追逐、受伤、冲刺状态；通过信号报告尖叫预警、痕迹和死亡，不直接访问游戏世界。
- `hunter_stats.gd`：属性定义。新增变种时复制 `.tres`，调整速度、血量等，再交给刷新管理器。
- `hunter_visual.gd`：模型与材质；`hunter_voice.gd`：短尖叫生成与播放。
- `hunter_director.gd`：数量和空间刷新，世界只负责装配目标、技能区域和事件连接。

因此单独把 `hunter.gd` 挂到 CharacterBody3D，配置属性模板并指定 `target` 即可使用；不依赖完整雨夜世界。树林绕行目前采用近距离射线避障，复杂障碍绕行仍不等同于完整导航网格寻路。

规则检查命令：

```bash
Godot --headless --path . --scene res://tests/hunter_rules.tscn --max-fps 60 --quit-after 600
```

预期输出 `HUNTER RULES PASS`。

## 重开、性能及平衡更新（2026-10-12，覆盖前述十只配置）

- 当前数量 **六只**。普通速度 **3.2**，冲刺速度 **7.8**，触发距离 **8 米**；预警 0.8 秒、冲刺 5 秒、休息 8 秒不变。后退 2.5、步行 5、奔跑 7.5 不变。
- 首次生成分布在玩家四周六个带随机偏移的扇区；以后远距离刷新和死亡补位按玩家运动方向前方生成。始终检查碰撞。
- 重开从即时 `free()` 改为 `queue_free()`，等待旧场景释放再生成新世界。主控制器持续处理重开，游戏世界仍正常受暂停控制；重开有重复点击保护。
- 奶龙网格/材质/Shader只生成一次，通过 PackedScene 缓存共享，节点、血量、碰撞和AI仍独立。森林细节树最多缓存十二个活树/枯树模板，仍带随机位置、旋转和缩放；所有树枝、树根、树皮和针叶细节保留。
- 第一次进场显示准备提示后再创建世界；仍有首次资源上传和驱动编译成本，并未实现后台线程加载。
- 局部CPU测量：六只独立生成 47.25 ms、建立一次缓存 8.95 ms、六只共享实例化 0.95 ms。只测模型准备阶段，不代表总体帧率。

2026-10-12 参数更新：奶龙冲刺持续 **2 秒**，休息仍为 8 秒。雷暴间隔除以 2.5：正常模式由 8–16 秒缩短为 **3.2–6.4 秒**，首次闪电约 **4 秒**；减少闪光模式间隔为 4.4–7.6 秒，继续保持低闪光强度。间隔不包括单次闪电自身的 0.42 秒。

## 包围刷新与地图落雷（覆盖此前六只/远距离规则）

当前保持五只。玩家实际奔跑、后方奶龙至少落后28米（原65米）、视野中没有奶龙时，随机选最多三只传送到运动方向前方16–24米。批量传送间隔8秒；敌人保留血量，传送后进入休息。初始依旧环绕生成。视线与运动方向分别判断：回头看到敌人时不会把它传走；只看向后方空处且敌人仍在视野外时，可向实际运动前方刷新。未找到不碰撞的位置则重试。

雷电现在在地图±85米内随机落点，显示48米高的分叉闪电，使用落点上方18米处的单个带阴影OmniLight照亮全场。光线方向由落点决定，不跟随玩家；点光受距离衰减，模型表面按法线和遮挡产生亮暗。背光面可保留黑色轮廓。雷声为落点处的3D声音，按距离估算延迟（距离/343+0.08秒）。保留现有打雷频率及减少闪光模式。点光和单点雷电照明是实时游戏近似，并非完整闪电体积光模拟。

## 近身黑暗可读性与研究说明

近身补光范围4.5米，位置在身体下方，柔和衰减并保留阴影、不向体积雾注入亮度。帮助玩家辨认地面、树根和障碍；远处仍由雷光揭示。属于游戏可读性补光，不是真正“零光照下视觉”。

实际研究流程：选1–3门学科 → 三份记录逐份靠近按E收集 → 按装备顺序轮流设为Lv.2 → 收齐后到出口按E逃脱。重复记录不计数；重复升级同一技能仍停在Lv.2。升级目前影响雷痕持续时间、泥浆/盐阵范围、盐阵消耗及鲁米诺显示规则，还声/剥噪没有额外Lv.2参数。融合为满足操作组合条件后写入手册，不会生成新技能。已修正泥浆＋还声说明，使其符合奶龙全图锁定、不会受声源诱导的现行规则。
