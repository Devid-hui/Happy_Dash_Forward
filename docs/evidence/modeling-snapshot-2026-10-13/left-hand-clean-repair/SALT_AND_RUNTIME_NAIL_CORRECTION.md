# Verified corrections after the first source freeze

The first production source (`7c8a49d3...`) had a verified salt-only failure: the independent whole-hand audit found 365 strict nonadjacent triangle crossings, mainly 359 Index/Thumb crossings and six Thumb/palm base crossings. The earlier tool-skin distance samples did not test these self-intersections and cannot be cited as proving an unbroken tool grasp.

The isolated full-surface probe found that Index MCP side clearance of −12 degrees around the source palm Y axis, plus two degrees of Thumb CMC opening around the same anatomical source axis, removed the crossings without changing the main pose, hand geometry, weights, or other tool poses. A −10/2 candidate still had 52 crossings; an initial status message misread that row, was corrected before accepting it, and that candidate was not used for production. The accepted salt grip socket also moves two millimetres along hand X to keep the actual pouch near the thumb pad.

The revised source is `06e36f74a2abbb3dda173b070c3431ed6a15d4f4d872958242597a3eab5e08dd`; exact code and three-GLB hashes are in `production-sha256.json`. `salt-scope-proof.json` compares its actual neutral mesh, evaluated main shape, main joint matrices, and both other tool pose maps against the preserved first production source. The main and other tools remain unchanged.

Full-point distance checking found one anomalous value at thumb vertex 90476. The fixed single ray reported −4.173 mm, but the actual nearest surface was 4.173 mm away on the outside. Seven different rays all classified it outside. `salt-distance-witnesses.json` preserves the point, nearest point/normal, and ray results. This is a validation-ray degeneracy, not evidence of a deep physical intersection; the original report is retained rather than silently discarded. The other full-point index pressures were below 0.6 mm. The final independent full-surface audit remains the authoritative self-crossing result.

The native nail edge problem also had a specific verified cause. All three left skin/nail primitives contained standard COLOR_0 and shared the same embedded diffuse image. At 301 shared body/plate positions, normals, UVs and vertex colours were identical. Actual Godot material inspection showed that the body material had `vertex_color_use_as_albedo=false`, while plate and edge had it enabled. Consequently, the compensated diffuse was multiplied by the pigment coefficient only on the nail surfaces. The parent added a left-only runtime compatibility correction that explicitly enables linear vertex colours on every corresponding material. Native rendering confirmed that the dark, jagged material boundary disappeared. No source nail repositioning, new mask, material consolidation, or right-hand colour change was required for that correction.

The accepted first source master is preserved in `production-before-salt-release`. An attempted runtime snapshot overlapped the generator and contains mixed old/new files; it is explicitly retained as `production-salt-build-intermediate` and is not claimed to be a full previous three-GLB snapshot. The full originals from before this source task remain in `production-before`.
