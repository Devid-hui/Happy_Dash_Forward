# UV/PBR source and workflow references

The exact Blender 4.5 manual chapters below were fetched through direct local HTTP and read. The web tool's initial 402 response was a tool fetch limitation; local copies of the actual pages and extracted article text are preserved under `references/`.

- [Blender 4.5 UV introduction](https://docs.blender.org/manual/en/4.5/modeling/meshes/uv/unwrapping/introduction.html): unwrap when geometry is mostly stable; changed faces may need subsequent mapping edits. This is why the isolated body study uses the frozen c3 source and leaves the face owner's changing prototype separate.
- [Blender 4.5 seams](https://docs.blender.org/manual/en/4.5/modeling/meshes/uv/unwrapping/seams.html): seams create UV discontinuities, so a source vertex can legitimately have multiple corner UVs. The transfer artifact preserves original face/corner correspondence rather than assuming one UV per original vertex.
- [Blender 4.5 Cycles baking](https://docs.blender.org/manual/en/4.5/render/cycles/baking.html): baking requires real UV coordinates and an active image target. Emission/color-only passes transfer surface color without baking lighting. Margins prevent filtering and mipmap seam discontinuities. Animated-object normal maps normally use tangent space and, when transferring detail, a real high-to-low projection/cage.
- [Blender 4.5 glTF export](https://docs.blender.org/manual/en/4.5/addons/import_export/scene_gltf2.html): recognized Principled/image nodes export real PBR textures and UVs. Vertex colors are Base Color multipliers, so a full baked albedo must not also multiply the original color. Actual installed 4.5 operator RNA and real exported GLB bytes were separately inspected.
- [xatlas upstream](https://github.com/jpcy/xatlas): MIT UV chart segmentation/parameterization/packing source with output `xref` correspondence. [xatlas-python](https://github.com/mworchel/xatlas-python) supplies MIT bindings, version 0.0.11 installed only in this trial's private environment. The current installed API spelling `get_mesh_vertex_assignment` and RGB chart image shape were checked with a real quad before the current full solve; the README contains an older misspelling.

`SOURCE_AND_API.json` records the actual source material, empty Body UV state, color domain and installed operator capabilities. `BAKE_COLORSPACE_PROBE.json` records a real 64px sRGB emission bake, independent PNG decoding and two actual GLB material/attribute exports. The byte-image `image.pixels` API returned sRGB-encoded values; linear comparisons explicitly decode them. The chosen body export uses `MATERIAL` with `export_all_vertex_colors=False`, preserving editable original colors in the source while avoiding a duplicated COLOR_0 multiplier.

This work does not invent skin noise or pass a solid normal/roughness image off as measured detail. The source's roughness .48 and geometric normals remain until a justified high-to-low detail transfer exists. Body UV/color texture proof alone is not completion of all character UV/PBR work.
