**不可缩减的交付边界**

- 谱灯是可见的便携科研仪器，不占技能槽。常态单手持握；集中爆发时另一手辅助支撑，释放后恢复；照明、爆发、点射各有对应动作。
- 原六项技能保留，蓄昼与乱频加入八项可选技能，最多装备三个。施用、布设、投放类按用途制作器具与动作，感知类通过仪器模块、操作、界面及声光表现；不强制每项新增独立器具。
- 照明、爆发、点射、加速共享电量，并保留基础慢速恢复。蓄昼被动捕获闪电的光、主动耗电加速；乱频主动切换爆发／点射，点射按次耗电并积累噪声；照明独立开关。
- 三份报告各提供一次暂停自主强化，从谱灯及本局已装备技能中选择；每个能力为基础、进阶、精修三级，不引入分支树。集齐三份后开启出口；三次强化允许专精或分散，不要求全部能力满级。
- 副作用明显但可控，包含视听干扰与短促步态偏移，保留基本操作。减弱画面干扰时保留资源与战术代价；暂停、手册和菜单可用。
- 雨夜保留黑暗压迫感，近处道路与障碍轮廓可辨；谱灯显现局部模型和材质细节，闪电揭示远处。奶龙采用常见圆润黄胖形象，危险感由表情及追逐动作形成，不采用未选的畸变或双形态造型。
- 重复网格、材质和纹理共享，动画实例及局部反馈独立。视觉动作不额外移动物理根，动画边界覆盖各姿态；仍在视野边缘可见的追猎者不能被传走。
- 本局能力重置，知识、报告和融合发现独立保存为跨局档案，不提供永久数值优势。科学说明区分真实原理与游戏放大。
