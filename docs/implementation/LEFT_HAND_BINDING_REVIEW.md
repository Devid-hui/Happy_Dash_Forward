## 修复顺序

1. 在相同姿态下对照成熟原始权重的线性／保体积蒙皮，撤除为旧拇指姿态添加的权重平滑、限幅及普通网格平滑，辨认失真来源。
2. 若固定旧掌摆向迫使拇指大幅旋转，重新安排整掌及四指的自然握姿；保留正确的手性、骨长、指腹接触方向与肩肘走向。
3. 先让握姿避开穿插。不得用指腹压缩把深穿插推成硬片；只对已确认的浅表接触作有限修正。
4. 必要时使用参照中立形态的局部姿态修形，逐项保留依据，避免普通 Smooth 反复抹平整体手形。
5. 最终重新检查完整左手与三种器具姿态，并在相同导入资产的 Godot 原生三视图、完整举灯／收手动作中验收。
