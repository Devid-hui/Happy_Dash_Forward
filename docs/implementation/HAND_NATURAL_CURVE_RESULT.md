# 手掌倾角、自然弧度与肩肘：本轮交付

2026-10-13。本轮已接入实际 Godot 项目，并完成源码、绑定、原生动作及局部逻辑检查；用户的最终外观认可与四阶段整体完成仍独立保留。

## 当前已实现

- 左掌从世界水平平托改为绕灯筒轴−18°斜抱，手掌位置沿同一圆周调整；右握绕柄轴6°轻微斜抱。两骨长度保持，前臂随真实腕目标适配，不单独把腕掰成直角。
- 在成熟CC0源手加入左3.8mm、右2.8mm浅横掌弓，指根与指链一致随形；这些是本项目参数，不是人体统一标准。
- 拇指按源模型独立的甲面/指腹方向设定屈曲平面，形成回扣；四指保留独立自然弧度，小指不再强行追不可达的高处接触点。
- 双侧袖型使用同一CC0 hm08测量截面与连续无过冲插值；保留袖口，肘附近局部圆角及权重覆盖相应圆角段。骨轴仍是正常上臂/前臂两段。
- 灯与双手整体向身体回收55mm、向画面中心35mm、下移18mm；肩肘保留小幅配合。点射视觉回弹22mm，左手退场高度改善。耗能、命中和冷却保持即时执行。
- 指腹局部接触修形上限3mm；深于3.5mm的点不靠该修形遮掩。当前源主灯最深剩余约0.391mm；盐拇指约1.52mm。鲁米诺/泥罐的少数接触区域仍有约2–2.43mm局部残余，明确未声明所有工具零穿插。

## 证据

- 最终三视图236帧，均为实际Godot 4.7.2 / Metal 4 / M4 Pro的1920×1080渲染，分别包含第一人称完整动作158帧、左右侧前方举灯各39帧。
- 源文件修改时间早于首帧；九项关键代码/GLB哈希在捕获中记录并于结束核对一致。
- 手部552项、静态资产、谱灯37项逻辑/物理检查全部干净通过，后两者使用隔离档案。动态腕角最大约48.598°；原55°阈值未放宽。
- 左稳托肘屈曲约83.13–84.98°，右约70.18–76.88°（0°表示伸直）；两段骨长误差在浮点舍入范围。这些是该姿态实测，不是人体标准。
- 修复手部检查器原先assert失败后仍打印PASS/退出0的问题；现在失败明确累计并退出1。盐握姿用四元数分量等价核对，避免相同单精度四元数通过acos得到伪角差。
- 预览为受控动作，不是普通鼠标键盘整局游玩。诊断场景关闭TAA，正式渲染配置不变。

主要证据：final-motion/validation.json、final-motion/first-person/hand-and-arm-motion.mp4、source-final-receipt.json、SOURCE_IMPLEMENTATION.md。首版试调的交叠和第二版穿柄均已标记拒绝并保留对照，没有冒充最终结果。
