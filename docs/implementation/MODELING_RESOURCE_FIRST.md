# 建模优化：先查公开源文件与教程

2026-10-13 用户明确要求：后面所有建模优化工作，都先找开源的建模素材文件和指导教程，少走弯路。该要求覆盖本项目后续角色、人体、武器／器具、植被、环境和动作优化。

每次开始一个建模子项前，先完成与该问题相关的资源核查，再制作：

1. 查找可用的开源模型、可编辑源文件、骨架／权重／动作范例，以及作者或官方指导教程。优先官方、原作者和成熟项目；不以搜索数量作为完成标准。
2. 核对原始来源、作者、许可证、可商用／修改／再分发条件、格式和依赖。公开可看、免费下载、开源可复用分别记录。
3. 对决定采用或对照的资源，能公开取得就下载并实际打开；检查网格、拓扑、UV、材质、骨骼、权重、动作和导出兼容性中与本次问题有关的部分。保留原件、版本及必要校验记录。
4. 先决定直接复用、基于成熟底模改造或仅参考方法。合适的源资产优先复用；没有合适资源时记录具体缺口，再自行制作。被用户否定的资源不得重新当作方案推荐。
5. 把教程方法映射到当前模型的具体问题，做最小可见样例；先检查比例、轮廓、关节和接触，再补细分／纹理。动画必须查看完整动作，而非单帧或角度数字。
6. 在实际 Godot 导入后的相机、光照与动作中验证。资源可下载、模型能打开、面数高、导出成功或合同通过均不等于外观验收。

这是现有建模任务的执行顺序，不新增购买、账户、上传、插件安装或持久模式。没有现成适用资源时，完成可查证的调查后继续已授权制作，不反复询问是否继续。
