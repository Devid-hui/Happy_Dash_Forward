# Happy Dash Forward — The Midnight Academy

Godot 4.7.2 first-person horror survival prototype. The game project is documented in Chinese in [README_ZH.md](README_ZH.md); asset attribution and licenses are listed in `assets/*/ASSET_LICENSE.txt` and [README_ASSETS.md](README_ASSETS.md).

## Run

Open `project.godot` with Godot 4.7.2 Standard, then press F6/F5. From a terminal:

```sh
godot --path .
```

The repository contains source scenes, scripts, resources, and game assets. Godot import caches and local macOS build products are excluded; export a build locally from the project.
